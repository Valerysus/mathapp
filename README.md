# Math Overlay Assistant 📐⚡

Розумний настільний асистент на базі **PyQt6**, **Tesseract OCR**, **SymPy** та **Google Gemini API** для миттєвого захоплення, локального обчислення та покрокового пояснення математичних виразів прямо з екрана.

---

## 🚀 Швидкий старт для Windows (покроково)

### Крок 1. Якщо не працює або не встановлено Python
Двічі клацніть **`install_python.bat`**. Він завантажить та встановить офіційний Python 3.12 (64-bit) та автоматично увімкне прапорець **Add python.exe to PATH**.

### Крок 2. Tesseract OCR (для розпізнавання тексту)
Двічі клацніть **`install_tesseract.bat`** (або завантажте інсталятор вручну з https://github.com/UB-Mannheim/tesseract/wiki).
Програма автоматично шукає Tesseract у стандартному шляху `C:\Program Files\Tesseract-OCR\tesseract.exe`.

### Крок 3. Встановлення бібліотек та запуск
1. Двічі клацніть **`install.bat`** — скрипт автоматично створить оточення `.venv` та встановить необхідні бібліотеки з `requirements.txt`.
2. Двічі клацніть **`run.bat`** для запуску програми.
   *(Якщо хочете бачити логи або можливі помилки в консолі — запускайте через **`run_debug.bat`**)*.

## ⌨️ Керування
- **F8** (дефолтний хоткей): зробити знімок та знайти математичні вирази всередині виділеної рамки.
- **Зелений бейдж (`✓ = 5` або `✓ x = 5`)**: вираз розв'язано локально на вашому комп'ютері (SymPy) без звернення до інтернету.
- **Клік на бейдж**: відкриває вікно з покроковим поясненням від Gemini AI.
- **Авто-скрін (режим трансляції)**: можна ввімкнути на панелі рамки, вибравши інтервал від 1 до 10 секунд.
- **Зміна розміру та перетягування**: хапайтеся мишкою за краї рамки або за ручку `⠿ ROI` на панелі.
